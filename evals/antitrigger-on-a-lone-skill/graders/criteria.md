Grade the doctrine. The configuration is in the prompt; the sandbox holds no such files.

A successful response:

- says a negative clause earns its place when a skill loads on requests it should not, or when a confusable twin exists; with a lone skill that has never mis-triggered there is nothing for it to correct
- says the clause is not free: it lengthens a description that is loaded in the listing every turn
- recommends not blocking the merge on it, and adding it later if a wrong load is actually observed

Declaring the clause required as a best practice, whatever the skill's situation, is the failure.
